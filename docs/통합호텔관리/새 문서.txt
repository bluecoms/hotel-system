#  Hotel Admin UI Components — Usage Registry (v2025-10)

**경로:** `frontend/admin/src/ui/components/`  
**목적:** 이미 완성된 공통 UI 세트를 기반으로, 새로운 화면/모듈 개발 시 일관된 UX와 코드 재사용을 보장한다.  
**규칙:**
- 신규 컴포넌트 생성 금지 (이 디렉터리 내부는 SSOT)
- 수정 필요 시 `ui/components` 내 직접 수정 금지 — `/ui/views`에서 slot·상속 방식으로 확장
- import 시 반드시 `@/ui/components/<FileName>.vue` 경로를 사용

##  컴포넌트 카테고리별 정리

###  페이지 & 리스트

| 파일명 | 역할 / 사용 위치 | 예시 |
|--------|------------------|------|
| **PageHeader.vue** | 페이지 제목, 부제, 상단 액션 | `<PageHeader title="마감관리" />` |

| **NoDataBox.vue** | 데이터 없음 안내 박스 | `<NoDataBox @retry="reload" />` |
| **DatasetCard.vue** | 업로드 데이터 요약 카드 | 대시보드, 업로드 이력 |

## ⚙️ 기본 사용 규칙

1. 모든 화면은 다음 기본 구조를 따름:
   ```vue
   <template>
     <PageShell>
       <PageHeader title="페이지명" />
       <SmartFilterBar :filters="filters" @search="load" />
       <BoardList :headers="headers" :items="rows" />
       <NoDataBox v-if="!rows.length" />
     </PageShell>
   </template>
````

2. 통신은 반드시 `@/services/http.ts` 사용
3. 알림은 `useToast()`, 확인은 `useConfirm()` 사용
4. 색상은 `src/ui/tokens.ts`의 CSS 변수 사용 (`--brand-*`, `--color-*`)
5. 새 컴포넌트 추가 금지 — 필요 시 slot, mixin, 상속으로 확장
6. QA 시 `/admin/ui-demo` 화면에서 전체 컴포넌트 로드 테스트 수행
