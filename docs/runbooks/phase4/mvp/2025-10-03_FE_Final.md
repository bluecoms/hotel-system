# 📢 [PM-Hub] Phase 4 최종 결과 보고 (FE-Core 관점)

## 1) 공통 / 환경
- HTTP: `@/services/http` (fetch 기반, axios 금지)
- 헤더: `X-Internal-Token` 자동 첨부, `Accept-Language: ko-KR` 기본
- 권한: `SUPERADMIN` → 모든 권한 패스 / `ADMIN` → OTA·Reports 등 접근 가능
- 라우팅: `/api/menu` 응답 기반 메뉴, roles 불일치 항목은 숨김
- Dev 환경: `/api → 127.0.0.1:8000` 프록시, Fallback 메뉴 → API 응답으로 덮어쓰기(1회 흔들림 존재)

---

## 2) 완료된 화면 기능

### (A) Upload / Sales Front
- 경로: `/admin/upload/sales-front`
- 기능: CSV 업로드 → 드라이런 → 적용
- DoD: 드라이런 성공 후 “적용” 버튼 노출, 실제 업로드 시 재호출(dry_run=0)
- 증빙: `upload_dryrun.png`, `upload_apply.png`

### (B) Reports / Sales Tags
- 경로: `/admin/reports/sales-tags`
- 기능: 기간별 조회 + 합계 카드/푸터 + CSV Export
- 빈 배열 → "데이터 없음", 합계=0 유지
- Export CSV: `sales-tags_YYYYMMDD-YYYYMMDD.csv`
- 증빙: `sales_tags_export.png`

### (C) OTA / Channels, Commissions
- 경로: `/admin/ota/list`, `/admin/ota/commission`
- 기능: 목록 조회 + Commission CRUD
- 페이징: limit/offset 적용, Vuetify v-data-table 연동
- 증빙: `paging_channels.png`, `paging_commissions.png`

### (D) i18n + 공통 UX
- i18n 한국어 적용 (`messages.ko.json`)
- `StateBlock.vue`: 로딩/빈/에러 통일
- `format.ts`: KRW/날짜 포맷 적용
- Toast 메시지 일원화(400/422 detail, 403 권한 없음 등)

---

## 3) 메뉴 / 권한 동작
- 로그인 직후 → Fallback 메뉴(여러 항목) 표시 후 `/api/menu` 응답으로 정정됨
- 새로고침 이후 → OTA, Reports 두 개만 노출(ADMIN 전용 정상 상태)
- 최종: ADMIN → OTA/Reports 메뉴 보임, USER → 숨김 + 직접 접근 시 403 스낵바
