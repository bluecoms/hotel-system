# 📄 \[PM 보고\] Hotel Admin --- 운영/개발 환경 정리 완료 보고서

## ✅ 1. 개요

Hotel Admin 시스템의 **운영 서버 자동화 복원** 및 **개발 환경 분리
구성**을 완료했습니다.\
운영(NAS)과 개발(로컬 PC)의 포트 및 실행 체계를 완전히 분리하여 안전한
병행 개발이 가능합니다.

## ✅ 3. 구성도

    📦 NAS (운영)
     ├─ Nginx :80  → /var/www/hotel-admin (프런트)
     │               └→ /api → 127.0.0.1:8000 (Uvicorn)
     ├─ Uvicorn :8000 (FastAPI 운영 백엔드)
     ├─ watch-uvicorn.sh (5분 감시)
     └─ DSM 작업 스케줄러
         ├─ HOTEL_SERVER_BACKEND
         ├─ HOTEL_SERVER_FRONT
         └─ Uvicorn Watchdog

    💻 개발PC
     ├─ Vite :5173 → /api → 127.0.0.1:8001 (개발 Uvicorn)
     └─ Uvicorn :8001 (--reload, 필요 시만 실행)
